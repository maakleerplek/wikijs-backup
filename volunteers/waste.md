# Waste Management

Maakleerplek handles: **restafval, PMD, papier en karton, GFT**.

Each subplek must deposit these in the black containers at the white gate (in closed bags).

## NOT Handled by Maakleerplek

These must go to the containerpark or specific collection points:

| Waste Type | Where |
|---|---|
| Glass | Glasbollen aan Stapelhuisstraat |
| Wood | Containerpark |
| Grof huisvuil | Containerpark |
| Electronics | Containerpark |
| Batteries | Bebat collection point / containerpark |
| Chemicals | Containerpark |

## Sorting Guide

Use the Ecowerf sorteerwijzer: [ecowerf.be/composteren-en-recycleren](https://www.ecowerf.be/composteren-en-recycleren)

Minimize raw material use. Think before you throw.
