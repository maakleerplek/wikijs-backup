# Authentik

Single sign-on (SSO) identity provider for Maakleerplek services.

> This service is planned but not yet deployed.
{.is-warning}

## Service Details

| Property | Value |
|----------|-------|

## Planned Configuration

Authentik will provide:

- Single sign-on for all Maakleerplek web services
- Integration with Microsoft Entra ID
- User provisioning and deprovisioning
- MFA support
